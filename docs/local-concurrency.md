# 本机并发一致性验收

`scripts/soak_local.py` 在新建的临时状态目录启动真实 HTTP 服务，检验当前单进程、两个 durable worker loop 的队列与审批一致性。它使用内置 Checkout 合成样例的固定 replay，**不调用模型，不测模型修复能力，也不是生产容量或长时间稳定性压测**。文件名中的 `soak` 不代表已经完成耐久性测试。

2026-11-07 的本机实跑已通过，耗时 18.047 秒：12 条任务得到预期终态，18 个作业全部结束，两个 worker 的验证区间实际重叠，最多尝试 1 次，6 条记忆无重复，原始样例摘要未变。239 个 HTTP 响应的 p50 为 78ms、p95 为 375ms，包含预期的 409 响应。这些数据只对应本次固定小样本；原始记录见 [local-concurrency.json](evidence/local-concurrency.json)。

在仓库根目录执行：

```powershell
.venv\Scripts\python.exe scripts\soak_local.py --python .venv\Scripts\python.exe --report .traceforge\local-concurrency\report.json --timeout 180
```

Linux/macOS 使用相应的 `.venv/bin/python` 路径。指定的 Python 需要已安装当前项目的运行依赖。驱动器本身仅使用标准库。脚本显式加载当前 checkout，**不是已安装 wheel 的验收**；wheel 验收另见 `scripts/smoke_release.py`。

固定工作量为 12 条 replay：6 条批准、3 条拒绝、3 条取消。首次用 `/api/demo` 注册样例，此后在同一项目中并发创建任务。取消在创建响应后立即请求，实际发生在 queued、investigating 或 awaiting_approval 中的哪个阶段，以审计事件为准。其他任务到达审批屏障后，先验证错误摘要返回 409 且状态不变，再对每条任务并发提交两次相同决策，要求恰好一次成功、一次 409。所有终态再次批准必须返回 409。重复取消必须保持终态且不增加取消事件。

脚本逐条检查状态迁移与事件顺序、批准摘要绑定、禁止审批前测试、外部观察器的 8 条测试及前后身份一致、基线 4 个失败与补丁后 8 个通过、完成事件和记忆恰好一次、拒绝/取消无测试与记忆、两份文件清单一致，以及携带报告的内容摘要和结论。完成后只读这个临时实例的 SQLite，检查任务唯一性、执行次数、两个 worker owner、队列清空和实际验证区间重叠；若没有观察到两个 worker 或两条重叠验证，验收失败，不声称已证明并发。

资源探针在运行前后对内置样例全部文件计算同一 SHA256，确认源码资源未变。HTTP、审计、指标与记忆均通过实际接口获得；仅 job lease 元数据通过自有临时 SQLite 的只读连接核对。模型凭据与代理等继承环境被清除，服务没有模型名或 API key，provider 地址额外指向不可用的 loopback 地址；健康状态、每条用量和汇总指标均要求 provider 调用为 0。脚本只自动批准这个专用临时实例里的已知合成样例。

服务绑定随机 `127.0.0.1` 端口，工作目录和状态目录隔离；不连接现有服务，不改现有任务。HTTP 禁止代理与重定向。总预算默认 180 秒，允许 60–600 秒，其中预留 25 秒让 worker 清理测试子进程并终止自有进程树；每个请求、等待和子进程都有时间上限。固定并发客户端数为 12。Windows 使用隐藏子进程和针对自身 PID 的 `taskkill /T`。Linux/macOS 需要 `ps`，清理前仅追踪这个服务的后代进程组，先请求服务优雅退出，再终止残余的自有进程组，覆盖测试进程另建 session 的情况。原始日志与 API 正文只在临时目录或内存中存在，结束后清除。

JSON 报告保留 `run-01` 等局部标识、动作和终态、计数、各阶段时延、每次 HTTP 的方法/端点模板/状态/耗时、汇总分位数、环境版本、样例摘要和核验结论。报告不包含真实运行 ID、凭据、源码、原始日志、API 正文或私人绝对路径；失败也写出已经完成的检查与受控错误代码。HTTP 时延使用单调时钟，阶段时延来自持久化事件时间，包含实际排队和本机调度影响；审批屏障等待不应被解释为处理耗时。分位数使用 nearest-rank，包含预期 409 响应，启动阶段的连接失败另外保留。

退出码 `0` 表示本次固定工作量的所有断言通过，`1` 表示失败、中断或超出预算。**只有实际执行后生成的报告才能作为本次验收结果**；脚本存在、静态检查通过、历史通过记录都不能替代本次运行。
